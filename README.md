# Arch-Internship-Todo-List
A sleek, dynamic, and responsive task management web application developed during my web development internship at **Arch Technologies**. Built using frontend engineering fundamentals, this app provides a smooth and interactive user experience for managing daily tasks.

## Features

- **Dynamic Task Management (CRUD):** Add new tasks instantly, mark them as completed, edit existing ones, and delete outdated tasks.
- **Data Persistence:** Integrated with `LocalStorage` so your tasks remain saved even after refreshing the browser.
- **Interactive UI/UX:** Features a beautiful glassmorphic dark theme layout with smooth hover effects, scale transformations, and a custom gradient background.
- **Smart Empty State:** Displays a friendly placeholder illustration when there are no tasks in the list.
- **Fully Responsive:** Optimized to work flawlessly across mobile, tablet, and desktop screens.

## Tech Stack

- **HTML5:** For structured, semantic layout components.
- **CSS3:** For advanced styling, gradients, backdrop filters (blur effect), and sleek animations.
- **Vanilla JavaScript:** For live DOM manipulation, event handling, and state management.

## How to Run the Project

To run this project on your computer, you only need a modern web browser (like Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari). No extra software installation is required.

1. Download all the project files (`index.html`, `style.css`, and `script.js`) and keep them together in the same folder.
2. Locate the `index.html` file inside your project folder.
3. Double-click on the `index.html` file, or right-click it and choose "Open with" your favorite web browser.
4. The application will instantly open and run perfectly in your browser.
